# Add-on Home Assistant : Monitoring

Tableau de bord de monitoring (mails IMAP, API HTTP, ping / TCP, SNMP) dans la barre latérale de Home Assistant.

Voir [DOCS.md](DOCS.md) pour l'utilisation. Le dossier `app/` est une copie du monitoring (version indiquée dans `config.yaml`) : à mettre à jour avec chaque nouvelle version de l'application.
