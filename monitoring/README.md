# Add-on Home Assistant : Monitoring

Tableau de bord de monitoring (mails IMAP, API HTTP, ping / TCP, SNMP) dans la barre latérale de Home Assistant.

Voir [DOCS.md](DOCS.md) pour l'utilisation. L'application est téléchargée depuis [Jcpasdutout/monitoring](https://github.com/Jcpasdutout/monitoring) à la construction, au commit indiqué dans `build.yaml` (`MONITORING_REF`). Pour une nouvelle version de l'application : mettre à jour ce commit et augmenter `version` dans `config.yaml`, sinon Home Assistant ne propose pas la mise à jour.
